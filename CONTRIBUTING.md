# Contributing [⌐■_■]

Thanks for contributing!

> The **detailed rules** live in [nanoolabs/contributions](https://github.com/nanoolabs/contributions) : AI use, PR expectations, and the contribution philosophy. Read it first.

## Discussions

We use [GitHub Discussions](https://github.com/nanoolabs/.github/discussions) for community conversation, separate from issues:

- 🔔 **Announcements**: release notes and project updates from the Nanoo Labs team.
- 💡 **Ideas**: propose a feature or experiment before it becomes an issue. Once we agree on the design, it is converted to an issue.
- 💬 **Q&A**: ask anything about using a Nanoo Labs project.

## Contributing

- **Bugs & features** : open an issue using the [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) or [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) template.
- **PRs** : follow the [PR template](.github/PULL_REQUEST_TEMPLATE.md), keep changes small and focused.
- **Commits** : [Conventional Commits](https://www.conventionalcommits.org/): `feat:` `fix:` `build:` `chore:` `ci:` `docs:` `style:` `refactor:` `perf:` `test:` + optional scope: `feat(api):` `fix(ui):`.
- **Code of Conduct** : see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **License** : contributions are licensed under the [MIT License](LICENSE).
